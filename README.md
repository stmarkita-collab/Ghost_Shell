# Ghost_Shell
GAME SIMULATOR GHOST SHEL
🎯 Tentang Game
GHOST//SHELL adalah game simulasi hacker bergaya terminal yang meniru alur kerja penetration testing sungguhan — dari reconnaissance, port scanning, exploitation, privilege escalation, sampai cleanup. Semua dikemas dengan UI/UX mobile-first bercita rasa cyberpunk neon.

Kamu berperan sebagai operator anonim yang menerima kontrak dari klien gelap di darknet. Setiap misi adalah target baru dengan tingkat kesulitan meningkat, dan setiap tindakanmu bisa meninggalkan jejak (trace) yang menentukan reputasimu.
Genre: Simulation / Text Adventure / RPG
Target Platform: Browser modern (mobile & desktop)
Bahasa: Indonesia (command tetap dalam bahasa Inggris teknis)

✨ Fitur Utama
🖥️ Terminal Simulasi Realistis
Command parser dengan autocomplete (TAB) dan history (↑/↓)

Output berwarna dengan ANSI-style styling

Progress bar animasi, header box ASCII, dan log realistis

Echo perintah + prompt dinamis (> / $ / #)

🎯 10 Fase Kill Chain
Setiap misi melewati 10 fase penetration testing:

SETUP → RECON → SCAN → ENUM → VULN → EXPLOIT → SHELL → PRIVESC → EXFIL → CLEAN

🐚 Interactive Shell
Setelah eksploitasi berhasil, kamu masuk ke shell target:

Perintah ls, cd, cat, find, sudo -l, ps, netstat

Filesystem virtual dengan file sensitif (.env, shadow, vault)

Prompt berubah sesuai level akses ($ untuk user, # untuk root)


⚠️ Disclaimer
Game ini adalah fiksi edukasional. Semua nama domain, IP, CVE, dan skenario adalah rekaan. Perintah yang ditampilkan (nmap, gobuster, hydra, msfconsole, dll.) adalah tool nyata yang digunakan profesional keamanan siber, tapi game ini tidak mengajarkan cara memakainya secara nyata.

Jangan pernah melakukan penetration testing tanpa izin tertulis dari pemilik sistem. Aktivitas hacking ilegal adalah tindak pidana di hampir semua yurisdiksi.

Dibuat untuk hiburan & edukasi tentang konsep cybersecurity awareness dan ethical hacking workflow.
